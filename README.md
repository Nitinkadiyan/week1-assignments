# ArtisanCraft - Handcrafted Products E-Commerce Landing Page

## Overview

ArtisanCraft is a responsive e-commerce business landing page designed for a handcrafted products store. The website showcases handmade products such as pottery, wooden crafts, candles, baskets, and decorative home items. It is built using only HTML, CSS, and JavaScript, making it beginner-friendly and easy to understand.

The project focuses on clean design, responsiveness, and basic interactive features that help create a professional online presence for a small handcrafted products business.
